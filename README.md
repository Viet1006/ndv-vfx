# NDV VFX - web demo

## ▶ [Open the demo: https://viet1006.github.io/ndv-vfx/](https://viet1006.github.io/ndv-vfx/)

Built from the Unity project with `ndv-vfx deploy` (updated 2026-11-13 13:29). This repo only holds the latest WebGL build.

- Link to one effect: `https://viet1006.github.io/ndv-vfx/?vfx=<id>` (the address bar updates when you pick an effect)
- Mouse: left drag orbit, right/middle drag pan, wheel zoom
- Keys: Up/Down prev/next, Space replay, F frame, T motion (Auto / Circle / Drag / Off), C colors / sky, G ground, M sound, H hide list
- Every effect has a `.unitypackage` download
